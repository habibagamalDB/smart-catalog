# Demo Bakery Content Checklist

Collect this from the demo bakery before Phase 2 (catalog). Items marked _optional_ can be added later.

## Brand and profile

- [ ] Bakery name in Arabic and English
- [ ] Short description (1 to 2 sentences) in Arabic and English
- [ ] Logo (SVG or PNG, at least 512x512, transparent background preferred)
- [ ] Cover or banner image (at least 1600x900) _optional_
- [ ] Brand color (hex) _optional_
- [ ] Catalog URL slug (lowercase letters, numbers, hyphens; for example `sweet-corner`)
- [ ] Order reference prefix (2 to 4 capital letters; for example `SC` gives `SC-1025`)

## Contact and location

- [ ] Phone number
- [ ] WhatsApp number (if different)
- [ ] Address in Arabic and English, plus a Google Maps link
- [ ] Business hours for each day of the week, including days off

## Ordering rules

- [ ] Pickup available? Delivery available?
- [ ] Flat delivery fee (EGP), and the areas covered, described in text
- [ ] Minimum order amount _optional_
- [ ] Default preparation lead time (for example 24 hours for cakes)
- [ ] Cut-off rules, for example "same-day orders before 12:00" _optional_

## Categories

For each category:

- [ ] Name in Arabic and English
- [ ] Display order
- [ ] Seasonal? If so, the date range when it should be visible

## Products

For each product:

- [ ] Name and description in Arabic and English
- [ ] Category
- [ ] Photos (1 to 5, at least 1200px on the long side, good lighting, no watermarks)
- [ ] Sizes or weights with a price for each (for example 1 kg: 650 EGP, 2 kg: 1200 EGP)
- [ ] Flavors or add-ons, with any extra price
- [ ] Preparation lead time, if different from the default
- [ ] Accepts a custom message (for example on a cake)? Maximum length?
- [ ] Featured? Currently on sale (sale price and end date)?
- [ ] Availability: available, limited, or sold out

## Promotions _optional_

- [ ] Banner image and title in Arabic and English
- [ ] What it links to (a category or product), and its start and end dates
- [ ] Announcement bar text (for example "Eid orders open until the 20th")

## Notifications and access

- [ ] Email address for the merchant dashboard login
- [ ] Telegram account to receive new-order alerts

## Permissions

- [ ] Written confirmation that the bakery owns the photos and allows their use
- [ ] Privacy notice contact details (who customers contact about their data)
